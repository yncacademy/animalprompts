Cute reef manta ray named GLIDE, with oversized golden eyes, a broad midnight-blue body, pale underside, elegant wing-like fins, curled cephalic lobes, and a tiny pearl anklet around one fin. A graceful reef dancer

high-end 3D animated feature reference sheet, portrait 4:5 board, original character, header “GLIDE” with tagline “WIDE WINGS / QUIET WONDERS,” traits “GRACEFUL / CALM / CURIOUS / KIND”

full-body turnaround — front / 3-4 / side / back / T-pose, wing shape, underside markings, cephalic lobes, pearl anklet, and proportions consistent, labels beneath each pose
