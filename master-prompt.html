Master prompt

The template behind all 100 sheets.

One structure, filled in 100 different ways. Copy the template, replace every bracketed field with your character's details, and you get a consistent character reference sheet instead of a one-off picture.

How to use it

Paste the whole template in one go. The bracketed fields are the only parts you change — the surrounding structure is what keeps the sheet consistent, so don't trim it down if you want the turnaround, expressions and detail panels to line up.

The master prompt

Universal character reference sheet prompt

Create a single vertical 4:5 character reference presentation board for an original cute 3D animated character.

CHARACTER:
[CHARACTER NAME], a cute [ANIMAL OR CREATURE] with [MAIN VISUAL FEATURES], [OVERSIZED OR DISTINCTIVE FEATURE], [SIGNATURE ACCESSORY], and [UNIQUE SILHOUETTE DETAIL]. The character has [BODY SHAPE], [HEAD SHAPE], [EYE STYLE], [FACIAL FEATURES], and a clear, memorable silhouette. Personality: [3–5 PERSONALITY TRAITS].

STYLE:
High-end 3D animated feature character design, original character, polished family-animation aesthetic, expressive chibi proportions, large rounded head, appealing readable silhouette, premium cinematic rendering, detailed but charming materials, soft stylized realism, consistent character design in every panel.

OVERALL PRESENTATION:
A professional character-bible model sheet displayed as one clean vertical presentation board. Use a neutral warm-grey studio background with subtle, low-contrast visual accents from the character’s natural habitat: [HABITAT]. Include faint [HABITAT ELEMENT 1], [HABITAT ELEMENT 2], and [HABITAT ELEMENT 3] only in the information panels and detail areas. Keep the main character views on uncluttered grey negative space. Use thin section dividers, clean editorial spacing, soft floor shadows, and consistent soft cinematic 3-point lighting throughout the entire board.

HEADER:
Top-left header with large clean uppercase text:
“[CHARACTER NAME]”
Under the name, include the two-line tagline:
“[SHORT TAGLINE LINE 1]”
“[SHORT TAGLINE LINE 2]”

Top-right corner contains four or five clean uppercase personality traits:
“[TRAIT 1]”
“[TRAIT 2]”
“[TRAIT 3]”
“[TRAIT 4]”
“[TRAIT 5]”

TOP SECTION — FULL-BODY TURNAROUND:
Show exactly five full-body character views arranged in one evenly spaced horizontal row:
1. FRONT
2. 3/4
3. SIDE
4. BACK
5. T-POSE

Every view must show the exact same character model, identical proportions, facial markings, colors, clothing, accessories, tail shape, ear shape, horn shape, wing shape, and surface details. Maintain the same eye line, body scale, lighting direction, and neutral standing pose across all views. Use clean uppercase labels beneath each view: FRONT, 3/4, SIDE, BACK, T-POSE.

The character must remain fully visible in every pose. Do not crop the feet, ears, tail, wings, horns, hands, or accessories.

SECOND SECTION — FACIAL EXPRESSIONS:
Below the turnaround row, show exactly four bust-length facial expression portraits in evenly spaced panels. Use these expressions:

1. [EXPRESSION 1]
2. [EXPRESSION 2]
3. [EXPRESSION 3]
4. [EXPRESSION 4]

Make the expressions highly readable through the eyes, eyebrows, mouth, cheeks, ears, horns, whiskers, trunk, snout, or other defining features. Keep the same head shape, facial proportions, colors, and character identity in every portrait. Add clean uppercase labels beneath each expression:
[EXPRESSION LABEL 1], [EXPRESSION LABEL 2], [EXPRESSION LABEL 3], [EXPRESSION LABEL 4].

MIDDLE SECTION — COLOR PALETTE AND CHARACTER INFORMATION:
Create a clearly separated information band beneath the facial-expression row.

On the left, show [4–6] circular color palette swatches with clean uppercase labels:
[COLOR 1] — [COLOR DESCRIPTION]
[COLOR 2] — [COLOR DESCRIPTION]
[COLOR 3] — [COLOR DESCRIPTION]
[COLOR 4] — [COLOR DESCRIPTION]
[COLOR 5] — [COLOR DESCRIPTION]
[COLOR 6] — [COLOR DESCRIPTION]

The swatches must match the actual character colors exactly.

In the center, show a small solid silhouette of the character beside a simple human height-comparison silhouette. Add the measurement:
“APPROX. [HEIGHT IN CM] ([HEIGHT IN FT])”

On the right, include a short clean character bio with the heading:
“[SHORT BIO HEADING]”

Write a concise two- or three-sentence bio describing the character’s personality, habitat, special ability, daily behavior, or emotional appeal:
“[CHARACTER BIO]”

BOTTOM SECTION — MATERIAL AND DESIGN DETAILS:
Create exactly four evenly spaced macro close-up panels along the bottom of the board. Each panel must focus on one important design feature and include a clean uppercase label:

1. [DETAIL LABEL 1] — close-up of [DETAIL DESCRIPTION]
2. [DETAIL LABEL 2] — close-up of [DETAIL DESCRIPTION]
3. [DETAIL LABEL 3] — close-up of [DETAIL DESCRIPTION]
4. [DETAIL LABEL 4] — close-up of [DETAIL DESCRIPTION]

Recommended detail subjects include:
EYE DETAIL, FUR TEXTURE, SCALE TEXTURE, FEATHER DETAIL, WING DETAIL, HORN DETAIL, PAW DETAIL, CLAW DETAIL, TAIL DETAIL, SHELL DETAIL, ACCESSORY DETAIL, or SKIN TEXTURE.

Show the material qualities clearly in the macro panels: [MATERIAL CHARACTERISTICS]. Use realistic surface variation while maintaining the same stylized animated design.

CHARACTER DESIGN SPECIFICATIONS:
[ADD ALL IMPORTANT MODEL-SHEET DETAILS HERE: body proportions, head-to-body ratio, limb length, tail design, ear shape, wing structure, horn placement, claw shape, markings, accessory placement, texture, and distinctive silhouette features.]

RENDERING:
8k render, ultra-clean character reference sheet, consistent model-sheet proportions, identical character model in every panel, polished 3D materials, expressive eyes, soft cinematic 3-point lighting, subtle contact shadows, controlled highlights, balanced neutral-grey composition, crisp section separation, professional presentation-board quality.

TEXT AND LAYOUT:
Use clean, minimal, uppercase editorial typography. Keep all labels aligned and legible. Maintain a clear hierarchy between the character, pose labels, expression labels, palette labels, bio, measurement, and macro details. Do not add unrelated text, random symbols, fake logos, watermarks, or extra design elements.

NEGATIVE PROMPT:
No extra characters, no duplicate character views, no incorrect animal anatomy, no inconsistent proportions, no redesigned accessories, no changing colors between panels, no missing tail, no missing ears, no missing wings, no cropped limbs, no extra limbs, no fused fingers, no distorted eyes, no warped face, no inconsistent markings, no cluttered background, no full scenic landscape behind the turnaround, no photorealistic animal, no horror features, no aggressive pose, no random text, no illegible typography, no watermark, no logo.

What makes the sheet hold together

  • The turnaround is described first and exactly. Five named views, with an explicit instruction that markings, accessories, proportions and eye line stay identical in every one.
  • Expressions are named, not described loosely. Four specific expressions, each anchored to a feeling — a labelled list beats “make it expressive”.
  • Colour is a labelled list. Naming each swatch is what stops the palette drifting between panels.
  • The bottom strip zooms into materials. Four macro panels, each with a label, so texture gets designed instead of left to chance.
  • The negative prompt is part of the prompt. Naming the failures up front — extra limbs, drifting colours, cropped tails, random text — is what keeps the board clean.

Adapt it

Swap the habitat and material lines for your character's world, and keep everything else. The template is deliberately generic in structure and specific in its requirements — that combination is what makes it reusable.
